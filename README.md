# Bahari Leo

How the sea feels on Kenya’s coast — kind, restless, or better from the sand, in ordinary words.

Kenya coast marine app built with Angular 22. Open **Today** for the daily pick, **Map** for pins and layers, **Places** for every stretch of shore.

Repo: https://github.com/waynegakuo/bahari-leo

Firebase project: **[bahari-leo](https://console.firebase.google.com/project/bahari-leo/overview)** (live). AI editions are generated by a Genkit flow on Cloud Functions (`functions/`).

## Firebase setup

Already done:

- Project **bahari-leo** created and linked (`.firebaserc`)
- Web app **Bahari Leo** registered — config in `src/environments/`

Before first deploy, finish in the [Firebase console](https://console.firebase.google.com/project/bahari-leo/overview):

1. **Firestore** — create a database (start in test mode or production rules; this repo ships `firestore.rules` that deny client access).
2. **Blaze plan** — required for Cloud Functions and Secret Manager (`GEMINI_API_KEY`).
3. **Gemini secret** — `firebase functions:secrets:set GEMINI_API_KEY`  
   Do **not** put `GEMINI_API_KEY` in `functions/.env` — Firebase loads `.env` as plain env vars on deploy and that clashes with the secret. For local emulator, use `functions/.secret.local` (see `.secret.local.example`).

Genkit Monitoring is enabled in `functions/src/telemetry.ts`. After deploy, open **Firebase console → Build → Genkit** to see traces, latency, and token usage.

Then deploy (functions run in **africa-south1**; production calls the function URL directly):

```bash
ng build
firebase deploy --only functions,firestore,hosting --force
```

Remove the old US function if it exists from an earlier deploy:

```bash
firebase functions:delete generateEdition --region us-central1 --force
```

## Development server

```bash
ng serve
```

Open `http://localhost:4200/`. Today’s three-panel strip uses the ordinary sea story until the Functions emulator (or a deployed function) answers.

## AI editions locally
For Windows:
```bash
copy functions\.env.example functions\.env
copy functions\.env.example functions\.secret.local
```

For MacOS:
```bash
cp functions\.env.example functions\.env
cp functions\.env.example functions\.secret.local
```

Put a [Gemini API key](https://aistudio.google.com/apikey) in both files, then:

```bash
npm run emulators
ng serve
```

`ng serve` proxies `/ai/generateEdition` to the emulator for project `bahari-leo`.
