# Bahari Leo

How the sea feels on Kenya’s coast — in ordinary words, not swell charts.

Kenya coast marine app built with Angular 22. Open **Today** for the daily pick, **Map** for pins and layers, **Places** for every stretch of shore.

## Development server

```bash
ng serve
```

Open `http://localhost:4200/`.

## Build

```bash
ng build
```

Output goes to `dist/bahari-leo/`.

## Tests

```bash
ng test
```
